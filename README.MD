
MECAI - Introdução à Ciência da Computação

Este repositório contém os exercícios práticos desenvolvidos para a disciplina de Introdução à Ciência da Computação(MAI5001) do MECAI.

Conteúdo do Repositório

O repositório está organizado em pastas que dividem os tópicos abordados na matéria:
• conceitos_basicos: Fundamentos iniciais da computação e sintaxe.
• estruturas_controle: Estruturas de decisão e laços de repetição.
• funcoes: Modularização de código e escopo de variáveis.
• inducao_recursao_recorrencia: Algoritmos recursivos e relações de recorrência.
• eficiencia_computacional_analise_assintotica: Análise de complexidade de tempo e espaço (Notação Big-O).
• algoritmos_ordenacao: Implementações de algoritmos para ordenação de dados.
• algoritmos_busca_e_hash: Mecanismos de busca linear, binária e tabelas Hash.
• busca_avancada: Algoritmos e técnicas aplicadas a buscas complexas.
• POO: Exercícios focados no paradigma de Programação Orientada a Objetos.
• grafos_arvores: Estruturas de dados não-lineares e seus respectivos algoritmos de manipulação.

Como Utilizar

1. Clone o repositório para o seu ambiente local:bash
git clone https://github.com/LeandroLDA/MECAI_introducao_ciencia_computacao

2. Navegue até a pasta do tópico desejado para acessar os códigos e resoluções dos exercícios.
